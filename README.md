# UI 动效库

给不写代码的人用的界面元素名词表：133 种常见的按钮、弹窗、动效、表单、加载状态和卡片，每种都能真的操作。先看它动起来是什么样，记住它叫什么，再把那句提示词交给 AI。

纯 HTML、CSS 和 JavaScript，不依赖任何框架或外部资源。

## 怎么看

GitHub 页面上看不到动效。下载仓库后，用浏览器打开 `index.html`。

| 页面 | 内容 |
|---|---|
| `01-buttons.html` | 按钮与开关 |
| `02-modals.html` | 弹窗 |
| `03-motion.html` | 动效 |
| `04-forms.html` | 表单 |
| `05-loading.html` | 加载与错误页 |
| `06-cards.html` | 卡片与列表 |

## 怎么让 AI 用

每种效果都有一个能单独运行的文件，放在 `snippets/`，里面只有这个效果用到的 CSS 和 JS，文件开头的注释写了用途、关键参数和提示词。

让 AI 编程工具先搜 `catalog.md` 找到合适的效果，再读对应的单个文件，把效果移植到你的项目里。这样不用让它读完整的大页面。移植时要注意：

- 颜色都是 CSS 变量，映射到项目自己的颜色。
- 演示里的定时循环和假数据要换成真实状态。
- `.sp`、`.stage` 和 `U.*` 只是演示外壳，不用带走。

## 修改

改 `src/pages/` 下的页面片段，然后运行：

```
python src/build.py
```

页面、`snippets/` 和 `catalog.md` 会一起重新生成，不要直接改这些生成的文件。

提示词里的时长等参数是建议值，可以按需调整。演示里的课程、人名、价格和文件都是虚构的。
